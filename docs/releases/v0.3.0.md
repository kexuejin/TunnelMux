# TunnelMux v0.3.0

TunnelMux `v0.3.0` is the biggest feature release since the tray build: per-route access gates, an in-app updater with SHA256 verification, and a fully multilingual desktop UI.

## Highlights

- **Service access gates**: a global default code plus per-service inherit / custom / public modes, with route-scoped cookies and a polished access page.
- **In-app updater**: checks the static `tunnelmux-latest.json` release manifest (GitHub API fallback), verifies SHA256, installs the raw archive, and offers **Restart Now**.
- **Multilingual UI**: English / 简体中文 switching from the header or Settings → Interface, with Auto system-language detection and local persistence.
- **DeepSeek / SPA preset**: one click to mount loopback-protected apps like DeepSeek Harness under a path, with correct Host/Origin handling and response path rewriting.
- **Route smoke tests** and **Test** actions on service cards.
- **Root-path policy hints**: each service card shows whether root `/` is exposed or stays closed.
- **UI polish**: wider, grouped settings/service drawers.
